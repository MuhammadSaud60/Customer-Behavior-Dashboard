# Customer Shopping Behavior Analysis

## Overview

This project analyzes customer shopping behavior using Python, SQL, and Power BI. The goal is to identify purchasing patterns, understand customer segments, evaluate subscription impact, and generate business insights through data analysis and visualization.

The project follows a complete data analysis workflow, including data cleaning, exploratory analysis, SQL-based business queries, and interactive dashboard creation.

---

## Objectives

* Analyze customer purchasing behavior
* Compare subscribed and non-subscribed customers
* Identify top-performing product categories
* Examine revenue distribution across age groups
* Explore discount usage patterns
* Build an interactive dashboard for decision-making

## Project Workflow

### 1. Data Cleaning and Preparation

* Checked for missing values
* Removed inconsistencies
* Created additional analytical features
* Standardized categorical values

### 2. Exploratory Data Analysis

* Customer demographics analysis
* Purchase behavior analysis
* Revenue distribution analysis
* Category performance analysis

### 3. SQL Analysis

Business questions explored:

#### Do subscribed customers spend more than non-subscribed customers?

Compared:

* Customer count
* Average purchase amount
* Total revenue

#### Which products receive the highest percentage of discounted purchases?

Calculated discount rates for products and identified top-performing items.

#### Additional Analysis

* Revenue by category
* Sales performance by customer segment
* Customer behavior trends

### 4. Dashboard Development

Built an interactive Power BI dashboard containing:

* Total Customers
* Average Purchase Amount
* Average Review Rating
* Customer Subscription Distribution
* Revenue by Category
* Sales by Category
* Revenue by Age Group
* Interactive Filters

---

## Key Insights

* Clothing generated the highest revenue among all categories.
* Most customers were non-subscribers.
* Young Adult customers contributed the highest sales volume.
* Average customer review ratings were generally positive.
* Product categories showed significant differences in revenue performance.
